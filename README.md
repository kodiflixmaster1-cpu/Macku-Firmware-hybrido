# Macku-Firmware-hybrido
Hybrid firmware for Makcu (MAKCM Dual ESP32-S3) with hardware USB passthrough and auto-detection. Supports USB mice (Boot/Gaming) and controllers (Xbox GIP, 8BitDo/XInput, PS4/PS5). Features real-time KM injection for relative mouse deltas or analog stick blending, click combining, and idle report synthesis.
